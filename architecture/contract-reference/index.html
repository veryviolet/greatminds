    This reference covers declared role/queue/task transitions, normalized runtime record fields, run state transitions and validated preset examples. Dynamic task/evidence checks still run in the domain services. The field tables are Python record contracts, not a complete YAML validation grammar: mapping keys supply IDs, manifests require transport: acp, and the manifest guide explains input configuration and constraints.

    Run state transitions¶

    State Permitted next states
    cancelling ["cancelled", "failed", "interrupted"]
    claimed ["cancelled", "interrupted", "starting"]
    running ["cancelling", "completed", "failed", "interrupted", "waiting_auth", "waiting_input"]
    starting ["cancelling", "failed", "interrupted", "running", "waiting_auth", "waiting_input"]
    waiting_auth ["cancelling", "failed", "interrupted", "starting"]
    waiting_input ["cancelling", "failed", "interrupted", "running"]

    Terminal states: cancelled, completed, failed, interrupted.
